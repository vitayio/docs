---
title: "Multi-factor authentication & login options"
description: "Set up MFA and other login options for your account."
---

Vitay supports two kinds of multi-factor authentication (MFA): a code sent to your phone by text
message, or a code from an authenticator app. You can turn on the text-message option yourself.
The authenticator-app option is turned on by Vitay support.

<Note>
  Every user can manage MFA on their own **Account** page. Vitay can also require MFA for your whole
  firm; contact [hello@vitay.io](mailto:hello@vitay.io) to set this up. When it's on, new users get
  text-message MFA automatically, users can't switch it off, and anyone with a phone number or
  authenticator app on their account is asked for a code at sign-in. Users with neither can still
  sign in without a code, so add a phone number to every account you want covered.
</Note>

## Turn on text-message MFA

<Steps>
  <Step title="Open your Account page">
    Click the person icon (**My account**) in the top bar.
  </Step>
  <Step title="Add a phone number">
    On the **Information** tab, add your phone number and click **Submit**. The MFA switch stays
    disabled until a phone number is saved.
  </Step>
  <Step title="Switch on Multi-factor authentication">
    Open the **Security** tab and switch on **Multi-factor authentication**. It saves straight
    away, and a **Profile updated** message confirms it.

    ![SCREENSHOT(mfa-and-login-options-security-tab): The Account Security tab with the Multi-factor authentication and Multi-factor Google authentication switches beside the password form](/images/placeholder.png)
  </Step>
</Steps>

## Set up an authenticator app

An authenticator app (Google Authenticator, Microsoft Authenticator or similar) shows a 6-digit code
that changes every 30 seconds. The **Multi-factor Google authentication** switch on the Security
tab stays disabled until Vitay support turns the option on, so start by asking
[hello@vitay.io](mailto:hello@vitay.io).

<Steps>
  <Step title="Stay signed in while support turns it on">
    From your next sign-in onward, Vitay asks for the app code, so scan the QR code before you sign
    out.
  </Step>
  <Step title="Open the QR code">
    Open **My account → Security** and refresh the page. The QR code appears under the
    **Multi-factor Google authentication** card.
  </Step>
  <Step title="Scan it with your authenticator app">
    Add an account in the app and scan the code. The app's current code is what you enter at each
    sign-in.
  </Step>
</Steps>

## What to expect at login

After your email and password, the **2FA verification** screen opens. Vitay asks for the
authenticator code if you have one set up, otherwise for a text-message code:

- Text message: click **Get code**, type the code sent to your phone, and click **Submit**.
- Authenticator app: type the current code from the app and click **Submit**.

Vitay asks for a code on every password sign-in, on every device. There's no "remember this device"
option. You have 10 minutes after entering your password to finish this step; after that, you start
again from the login page.

Wrong codes count toward the same limit as wrong passwords: 10 failures in a row lock the account.
See [Logging in](/getting-started/logging-in#troubleshooting) to unlock it.

## Turn MFA off

Switch **Multi-factor authentication** or **Multi-factor Google authentication** off on the
**Security** tab. If your firm requires MFA, the text-message switch is locked; contact
[hello@vitay.io](mailto:hello@vitay.io).

## SSO sign-ins

If you sign in with **Sign in with SSO**, your identity provider handles MFA. Vitay doesn't ask for
its own code on SSO sign-ins, even when your firm requires MFA. See
[Single sign-on (SAML)](/security-it/sso-saml).

## Troubleshooting

<AccordionGroup>
  <Accordion title="The Multi-factor authentication switch is greyed out">
    Hovering it shows **Phone number required** when there's no phone on your account. Add one on
    the **Information** tab. If you have a phone number and it's still locked, your firm requires
    MFA.
  </Accordion>
  <Accordion title="My authenticator codes aren't working">
    Codes depend on your device's clock, so make sure it sets the time automatically. If codes still
    fail, contact [hello@vitay.io](mailto:hello@vitay.io) before you reach 10 failed attempts and
    lock the account.
  </Accordion>
  <Accordion title="I've lost access to my MFA device">
    Contact [hello@vitay.io](mailto:hello@vitay.io) so support can reset MFA on your account. Root
    recruiters can't change another user's MFA settings.
  </Accordion>
  <Accordion title="I'm asked for a code but never set up MFA">
    Your firm probably requires MFA. Click **Get code** to receive a code on the phone number saved
    on your account. If that number is out of date, contact
    [hello@vitay.io](mailto:hello@vitay.io).
  </Accordion>
  <Accordion title="Vitay used to remember my device and now asks every time">
    That's expected. Every password sign-in now needs a code if MFA applies to you.
  </Accordion>
  <Accordion title="I signed out before scanning the QR code">
    The QR code only shows inside Vitay, and you now need a code to get in. Contact
    [hello@vitay.io](mailto:hello@vitay.io) so support can reset the option.
  </Accordion>
</AccordionGroup>
