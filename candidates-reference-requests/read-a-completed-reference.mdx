---
title: "Read a completed reference"
description: "View answers and scores once a reference is submitted."
---

When a reference completes the question form, Vitay records their answers and calculates scores automatically. You can review the full response at any time from the candidate's profile.

<Note>
  You need a recruiter (or higher) role to view completed references.
</Note>

## View a completed reference

<Steps>
  <Step title="Open the candidate">
    Go to **Candidates** and select the candidate whose reference you want to
    review.
  </Step>
  <Step title="Go to the References tab">
    Click the **References** tab. Each reference shows one of a fixed set of
    statuses: **Pending**, **Completed**, or **Unresponsive**. **Declined**
    only appears if your firm has switched on **References can decline the
    request** on the **Ref. Requests** settings tab — it is off by default, so
    most accounts never see this status. See
    [Reference request settings](/account-configuration/reference-request-settings).

    ![SCREENSHOT: the References tab showing a completed reference with status badge — placeholder](/images/placeholder.png)
  </Step>
  <Step title="Open the reference">
    Click the completed reference to open it. The reference view shows:

    - **Reference details** — the reference's name, title, company, relationship to the candidate, and the dates they worked together.
    - **Answers** — each question from the question set, with the reference's response. Question types include text responses, ratings (e.g., 1–5 or 1–10 scale), multiple-choice, dropdown, checkbox, and date fields.
    - **Score** — an overall numeric score calculated from the rating and matrix questions, displayed as a circle/dial. This gives a quick at-a-glance quality indicator.

    ![SCREENSHOT: the completed reference view showing question answers and the score dial — placeholder](/images/placeholder.png)
  </Step>
</Steps>

## How the score is calculated

Vitay scores a reference from its **rating** and **matrix** answers only. Text,
dropdown, radio, checkbox, slider, ranking and date answers are never part of
the score, and an answer the reference marked **N/A** is left out of it.

- **Rating questions** — Vitay averages the values the reference gave and
  divides that average by the rating scale. The scale comes from your firm's
  **Default rating scale** setting (**5** by default; **10** is the other
  option), so an average of 4 on a 5-point scale is 80%.
- **Matrix questions** — each row is scored against the **highest column
  weight** configured on that question, not against the number of columns. That
  way retiring a column doesn't quietly rescale the question. The **N/A**
  column a matrix always offers is not counted.
- **Both together** — when a question set contains rating *and* matrix
  questions, the reference's score is the average of the two results.

A worked example, for a question set with one rating question and one matrix
question:

| Answer | Score |
|---|---|
| A rating question answered **5** on a 5-point scale | 100% |
| A matrix row where the **4th of 5** columns is selected | 80% |
| **Reference score** | **90%** |

### The candidate score

The score in the circle at the top of the candidate page is the average of the
scores of that candidate's completed references. References that were declined
or deleted are not included, and the number moves as each new reference comes
back.

![SCREENSHOT: the candidate page header showing the overall candidate score dial — placeholder](/images/placeholder.png)

### Hiding scores

Scores are shown by default. A root recruiter can hide them everywhere — on the
candidate page, in lists, and on PDF reports — by switching off **Show
reference score** on the **Ref. Requests** settings tab. See
[Reference request settings](/account-configuration/reference-request-settings).

<Note>
  The score reflects only what the reference answered. If you are checking
  whether a reference is trustworthy as well as positive, look at the
  IP-conflict banner and the list of edits the candidate made to the reference's
  details — see
  [IP conflicts and reference edits](/candidates-reference-requests/ip-conflicts-and-reference-edits).
</Note>

## Download a reference report

To share completed references outside of Vitay (for example, to send to a
hiring manager), use the **Download report** button on the candidate's
**References** tab. You can download the full report covering all completed
references, or a report for a single question set. Reports download as PDF;
DOCX and CSV formats are also offered where they're enabled for your firm.

If you would rather send someone a link than an attachment, see
[Share reports](/candidates-reference-requests/share-reports).

## Troubleshooting

<AccordionGroup>
  <Accordion title="The reference shows as completed but I see no answers">
    This can happen if the reference submitted the form but the answer set is
    still syncing, or if the question set had no answerable questions. Refresh
    the page. If the problem persists, contact Vitay support.
  </Accordion>
  <Accordion title="The score seems lower than expected">
    Only rating and matrix answers count towards the score, so a question set
    built mostly from text or multiple-choice questions is scored on very few
    data points. Answers marked **N/A** are excluded too. A root recruiter can
    add rating or matrix questions to the set if you want the score based on
    more of the answers.
  </Accordion>
  <Accordion title="I can't see a score anywhere">
    A root recruiter has switched off **Show reference score** on the
    **Ref. Requests** settings tab. It hides scores on candidate pages, in
    lists, and on PDF reports for the whole account.
  </Accordion>
  <Accordion title="I need to correct an answer">
    Recruiters can edit individual answers after submission (for example, to
    fix a transcription error on a phone reference). Click the **Edit**
    (pencil) icon next to the answer. Text answers, rating values, and the
    comments on choice questions are editable; the selected option on
    multiple-choice and dropdown questions can't be changed.
  </Accordion>
</AccordionGroup>
