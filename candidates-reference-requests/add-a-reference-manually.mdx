---
title: "Add a reference manually"
description: "Enter a reference yourself instead of sending a request."
---

If you already have a reference's contact details, you can add the reference yourself instead of waiting for the candidate. Vitay sends the question set straight to the reference.

<Note>
  The candidate must already exist in Vitay. See
  [Add a candidate](/candidates-reference-requests/add-a-candidate).
</Note>

<Steps>
  <Step title="Open the candidate">
    Go to **Candidates** and click the candidate.
  </Step>
  <Step title="Click Add Reference">
    The button is in the toolbar of the **References** tab, next to
    **Reference Request**.
  </Step>
  <Step title="Fill in the reference's details">
    - **First name** and **Last name** are required.
    - **Email** and **Mobile number**: enter at least one. Your firm can make
      either one required.
    - **Company name**, **Reference job title** and **Reference type** (the
      relationship to the candidate, from your firm's list).
    - **Start date** and **End date**, when your firm has reference dates
      switched on.
    - **Question Set**, the questions this reference will answer.
    - **Language**, when your account has more than one language.
    - **Internal notes about the reference**, visible only to your team.

    If the candidate still has an open reference request, a message at the top
    of the form reminds you that they may add their references themselves.

    ![SCREENSHOT(add-a-reference-manually-modal): The Add Reference form with name, email, mobile number, company and question set fields](/images/placeholder.png)
  </Step>
  <Step title="Click Submit">
    A **Reference added** message confirms it. Vitay emails the reference the
    question set right away, or texts it when you only entered a mobile number.
    If your firm has **Reference review configuration** switched on, the
    reference is held for review and goes out once it's approved.
  </Step>
</Steps>

From here the reference gets automatic reminders (see
[Reminders and how they work](/candidates-reference-requests/reminders-and-cadence)),
and their answers appear on the reference once they submit (see
[Read a completed reference](/candidates-reference-requests/read-a-completed-reference)).

## Manual reference or reference request?

| | Reference request | Manual reference |
|---|---|---|
| Who enters the contact details | The candidate | You |
| Who gets the first email | The candidate | The reference |
| Use it when | The candidate should supply their own references | You already have the reference's details |

Either way, the reference gets the same email (or text) and the same form.

## Troubleshooting

<AccordionGroup>
  <Accordion title="I can't see the Add Reference button">
    The button is hidden when your firm requires the candidate's permission
    before references are added and this candidate hasn't granted it yet. It's
    greyed out on demo accounts and on candidates that belong to a different
    sub-account than the one you're viewing.
  </Accordion>
  <Accordion title="The email, phone number or ID is already linked to an existing reference">
    Your firm has **Prevent duplicate references** on (the default; a root
    recruiter can turn it off on the **References** settings tab). Vitay then
    refuses a reference whose email, mobile number or internal ID already
    belongs to another reference on the same candidate for the same question
    set. The same person can still be a reference for a different candidate, or
    for this candidate on a different question set. To change the existing
    reference, edit it instead.
  </Accordion>
  <Accordion title="The email field says personal emails not allowed">
    Your firm has switched off **Allow personal email addresses**, so Gmail,
    Yahoo, Hotmail and similar addresses are refused. Use the reference's work
    address, or ask a root recruiter to review
    [Reference settings](/account-configuration/reference-settings).
  </Accordion>
  <Accordion title="I entered the wrong email address">
    Click the reference to open it, click the pencil (**Edit reference**),
    correct the **Email** and click **Save**. Then click **Send reminder** so
    the request reaches the new address. See
    [Manage in-flight requests](/candidates-reference-requests/manage-in-flight-requests).
  </Accordion>
  <Accordion title="The reference says they didn't get the email">
    See [A reference didn't receive the email](/candidates-reference-requests/reference-not-received).
  </Accordion>
</AccordionGroup>
