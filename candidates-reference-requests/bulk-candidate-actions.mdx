---
title: "Bulk candidate actions"
description: "Select several candidates at once to deactivate them, update their status, assign a recruiter, send reminders, or send new requests."
---

Select candidates on the **Candidates** list and apply one action to all of them, for example to close out a filled role or hand a pipeline to a colleague.

<Note>
  Any recruiter can use bulk actions. They apply only to candidates you can
  see: if you only see your own candidates, that's all a bulk action touches.
</Note>

<Steps>
  <Step title="Open the Candidates list">
    Click **Candidates** in the left sidebar.
  </Step>
  <Step title="Tick the candidates">
    Tick the checkbox on each row, or the one in the table header to select
    the whole page. A bar appears at the bottom of the screen showing how many
    are selected. Its **X** clears the selection.

    ![SCREENSHOT(bulk-candidate-actions-bar): The Candidates list with three rows ticked and the bulk action bar at the bottom of the screen](/images/placeholder.png)
  </Step>
  <Step title="Click an action on the bar">
    Each action opens a dialog where you confirm, or pick a status, recruiter
    or request type, before anything changes.
  </Step>
</Steps>

## Available actions

| Action | What it does |
|---|---|
| **Send reminder** | Reminds every reference of the selected candidates who hasn't answered yet. |
| **Update status** | Gives every selected candidate the same status. |
| **Assign to recruiter** | Makes one recruiter the assigned user for all of them. |
| **Send new request** | Sends each candidate a new reference request, or a feedback or pre-screening request when those are on for your firm. |
| **Deactivate** | Moves the candidates to the Recycle Bin. Their data is kept. |

**Send reminder** follows the same limits as a single reminder: references that
already had 10 reminders, were reminded in the last 12 hours, have reminders
turned off, or whose last email bounced are skipped. See
[Reminders and how they work](/candidates-reference-requests/reminders-and-cadence).

**Send new request** asks for a **Question Set** and, for reference requests,
the **Minimum number of references**.

![SCREENSHOT(bulk-candidate-actions-send-new-request): The Send new request dialog with the Reference card selected and the question set and minimum references fields](/images/placeholder.png)

If an action fails for some candidates, the others are still processed and a
message tells you how many failed and why.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Assign to recruiter is missing from the bar">
    It's not offered while you're viewing all sub-accounts at once. Switch to a
    single account and select the candidates there.
  </Accordion>
  <Accordion title="Send new request doesn't offer feedback or pre-screening">
    Those request types appear only when the plugins are on for your firm. Ask
    a root recruiter, or see [Post-hire feedback](/feedback/post-hire-feedback)
    and [Pre-screening questionnaires](/candidates-reference-requests/pre-screening).
  </Accordion>
  <Accordion title="Fewer reminders were sent than candidates selected">
    Reminders go to references, not candidates, and references that hit a limit
    are skipped. A candidate whose references have all answered gets nothing.
  </Accordion>
</AccordionGroup>
