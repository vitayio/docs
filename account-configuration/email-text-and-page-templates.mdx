The **Emails**, **Texts** and **Pages** tabs let you rewrite the default wording Vitay uses for candidates, references and employers, per language, with merge fields such as the candidate's name.

<Note>
  You need the root recruiter role. The From address and name are set in [Email sender settings](/account-configuration/email-sender-settings). Which events send an email is set in [Notification settings](/account-configuration/notification-settings).
</Note>

## Edit a template

The three tabs work the same way. Each template is a card with its own toolbar.

<Steps>
  <Step title="Open the tab">
    In the Configuration area, click **Settings**, then the **Emails**, **Texts** or **Pages** tab.
  </Step>
  <Step title="Pick the language">
    If your account uses more than one language, choose one in the card's language dropdown. Each language has its own copy of the template.
  </Step>
  <Step title="Edit the text">
    Emails have an **Email subject**, an **Email title**, a **Button** label and a body. Texts have a plain body of up to 240 characters. Pages have a body.

    ![SCREENSHOT(email-text-and-page-templates-email-card): The Reference requests card on the Emails tab with the language dropdown, Variables menu, Send test button, and the subject, title and button fields above the editor](/images/placeholder.png)
  </Step>
  <Step title="Insert merge fields">
    Click **Variables** and choose a field to insert it at the cursor. Fields look like `{{field_name}}` and are replaced with real values when the message is sent. Only use the fields the menu offers for that template.
  </Step>
  <Step title="Let it save">
    Changes save shortly after you stop typing, or when you click away. The card shows **Saving…**, then **Saved**. If it shows **Not saved**, an error message explains why.
  </Step>
</Steps>

### Test, preview and reset

| Action | Where | What it does |
|---|---|---|
| **Send test** | Emails, Texts | Sends the saved template to your own email address or the phone number on your profile. Merge fields aren't filled in. |
| **Preview** | Pages | Shows the page text as it will look. Click again to go back to editing. |
| **Restore default** | All three | Puts back Vitay's default wording for that template and language and saves it. Only shown on cards you have changed. |

## Email templates

| Card | When it's sent |
|---|---|
| **Reference requests** | To the candidate, asking them to list their references. |
| **Reference requests - reminders** | Reminder to a candidate who hasn't listed their references. |
| **Reference** | To a reference, asking them to complete the question set. |
| **Reference - reminders** | Reminder to a reference who hasn't completed it. |
| **Candidate: Reference completed** | To the candidate when one of their references finishes. |
| **Candidate: Reference response still pending** | To the candidate when one of their references still hasn't responded. Shown only while **Candidate reference pending notification** is on (**Notifications** tab). |
| **Recruiter: Reference completed** | To your team when a reference finishes. |
| **Recruiter: All references completed** | To your team when every reference for a candidate finishes. |
| **Permission request to the candidate** | To the candidate, asking for consent. |
| **Feedback requests** (and reminders) | Feedback request to the candidate. Feedback plugin only. |
| **Employer Feedback requests** (and reminders) | Feedback request to the candidate's employer. Candidate Feedback plugin only. |
| **Pre-screening requests** (and reminders) | Pre-screening request to the candidate. Pre-screening plugin only. |

### Email merge fields

| Template | Fields in the Variables menu |
|---|---|
| Reference requests | `{{candidate_first_name}}`, `{{candidate_full_name}}`, `{{company_name}}`, `{{recruiter_full_name}}`, `{{nb_min_references}}` (not on the reminder) |
| Reference | `{{candidate_first_name}}`, `{{candidate_full_name}}`, `{{reference_first_name}}`, `{{reference_full_name}}` |
| Candidate: Reference completed | `{{candidate_first_name}}`, `{{candidate_full_name}}`, `{{reference_full_name}}` |
| Candidate: Reference response still pending | `{{candidate_first_name}}`, `{{candidate_full_name}}`, `{{reference_first_name}}`, `{{reference_full_name}}`, `{{recruiter_full_name}}`, `{{company_name}}` |
| Recruiter: Reference completed | `{{candidate_first_name}}`, `{{candidate_last_name}}`, `{{candidate_email}}`, `{{candidate_full_name}}`, `{{reference_full_name}}`, `{{reference_first_name}}`, `{{reference_last_name}}`, `{{added_by_full_name}}` |
| Feedback requests | `{{candidate_first_name}}`, `{{candidate_full_name}}`, `{{company_name}}`, `{{recruiter_full_name}}` |
| Employer Feedback requests | `{{candidate_first_name}}`, `{{employer_full_name}}`, `{{candidate_full_name}}`, `{{company_name}}`, `{{recruiter_full_name}}` |

When **Candidate job field** is on, `{{job_title}}` is also offered on **Reference requests** and **Reference**.

**Recruiter: All references completed**, **Permission request to the candidate** and the pre-screening cards have no Variables menu. The fields already in their default text still work if you leave them in.

## Text message templates

The Texts tab starts with an **Enable / Disable text messages** switch (on by default). When it's off, Vitay sends no text messages and the template cards are hidden. Texts only go to people with a mobile number on record.

| Card | When it's sent |
|---|---|
| **Reference requests** (and reminders) | To the candidate, asking them to list their references. |
| **Reference** (and reminders) | To a reference, asking them to complete the question set. |
| **Feedback requests** (and reminders) | Feedback request to the candidate. Feedback plugin only. |
| **Employer Feedback requests** (and reminders) | Feedback request to the employer. Candidate Feedback plugin only. |
| **Pre-screening requests** (and reminders) | Pre-screening request to the candidate. Pre-screening plugin only. |

The character counter turns red over 240 characters, and the text isn't saved until you shorten it.

| Template | Fields in the Variables menu |
|---|---|
| Reference requests | `{{candidate_first_name}}`, `{{recruiter_full_name}}`, `{{hiring_firm_name}}` |
| Reference | `{{reference_full_name}}`, `{{reference_first_name}}`, `{{candidate_full_name}}`, `{{hiring_firm_name}}` |

`{{job_title}}` is added to both when **Candidate job field** is on. The feedback and pre-screening texts have no Variables menu.

## Page templates

Pages are the blocks of text on the public forms.

| Card | Where it appears | Fields |
|---|---|---|
| **Reference request header** | Top of the candidate's reference request form | `{{nb_min_references}}` |
| **Reference header** | Top of the reference's form | `{{candidate_full_name}}`, `{{company_name}}` |
| **Reference Request - Submitted** | Message the candidate sees after submitting their references | None |
| **Candidate authorization** | Label of the extra checkbox on the candidate's form. Shown while **Candidate authorization checkbox** is on. | None |
| **Reference authorization** | Label of the extra checkbox on the reference's form. Shown while **Reference authorization checkbox** is on. | None |
| **Feedback request header** / **Employer Feedback request header** | Top of the feedback forms. Feedback plugins only. | `{{candidate_full_name}}`, `{{company_name}}` |
| **Pre-screening request** | Top of the pre-screening form. Pre-screening plugin only. | None |

`{{job_title}}` is added to the two headers when **Candidate job field** is on. The thank-you page references see after submitting is set on the **Leads** tab (see [Lead generation](/reports-lead-generation/lead-generation)).

![SCREENSHOT(email-text-and-page-templates-page-preview): The Reference request header card on the Pages tab in Preview mode](/images/placeholder.png)

## Languages

Vitay has default templates in English, French, French (Canada) and Spanish. The languages in each card's dropdown are the ones turned on in the **Multi languages** card on the **Plugins** tab. When you turn on a new language, Vitay creates its default templates, ready to edit. Your account's default language is on the **General** tab.

## Troubleshooting

<AccordionGroup>
  <Accordion title="My test email shows merge fields as literal text">
    That's expected. A test isn't tied to a real candidate or reference, so fields like `{{candidate_full_name}}` aren't replaced. Real emails fill them in.
  </Accordion>
  <Accordion title="I don't see the Feedback, Employer Feedback or Pre-screening cards">
    They only appear when the matching plugin is on. Contact **hello@vitay.io** if a plugin should be on for your account.
  </Accordion>
  <Accordion title="I don't see Candidate: Reference response still pending">
    Turn on **Candidate reference pending notification** on the **Notifications** tab. When it's off, the email isn't sent, so the card is hidden.
  </Accordion>
  <Accordion title="Send test is greyed out on the Texts tab">
    Text tests go to the phone number on your profile. Add one in [Your profile](/getting-started/your-profile) and reload the tab.
  </Accordion>
  <Accordion title="I broke a template and want the original back">
    Click **Restore default** on the card. Your edits for that language are replaced with Vitay's default wording.
  </Accordion>
  <Accordion title="There's no Restore default button on a card">
    The card already matches Vitay's default wording. The button appears once the text differs.
  </Accordion>
</AccordionGroup>
