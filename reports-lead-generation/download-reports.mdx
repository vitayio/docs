---
title: "Download reports"
description: "Export candidate, reference, lead, and activity data from Vitay as CSV files."
---

Export Vitay data as CSV files to build your own reports or keep records outside Vitay. Most exports start from the **Export** window in the top bar; a few live on their own pages.

<Note>
  You need a recruiter (or higher) role. Root recruiters always see the export buttons. Other users see them unless Vitay has turned report downloads off for your firm.
</Note>

## Export from the Export window

<Steps>
  <Step title="Open the Export window">
    Click the download icon in the top bar. The **Export** window opens.

    ![SCREENSHOT(download-reports-export-window): The Export window with the Tables dropdown, the Date range picker and the Fields list](/images/placeholder.png)
  </Step>
  <Step title="Choose a table">
    Pick a report from **Tables** (it starts on **Select a table to export**). See the list below.
  </Step>
  <Step title="Set the date range">
    Use **Date range**. Records are matched on the date they were created.
  </Step>
  <Step title="Pick your fields">
    Tick the columns you want under **Fields**, or leave them all unticked to get the standard columns. **Reference Answers Per Candidates** and **Candidates Per Recruiter** have fixed columns and show a dash instead.
  </Step>
  <Step title="Filter by question set (Reference Answers Per Candidates only)">
    A **Question set** dropdown appears for this table. Leave it on **All question sets** or pick one.
  </Step>
  <Step title="Export">
    Click **Export**. The CSV downloads to your browser.
  </Step>
</Steps>

The Export window always covers your whole firm for the chosen dates. It ignores any **Everyone** / **Myself** choice you made on a list page.

| Table | What you get |
|-------|--------------|
| **Answers** | Individual answer records |
| **Candidates** | Candidates with status, score, assigned recruiter, reference totals, and created date |
| **Reference Answers Per Candidates** | One row per completed reference, with a column per question |
| **Candidates Per Recruiter** | Per recruiter: candidates, references, leads, and whether they're active |
| **Feedback** | Feedback requests with created and completed dates |
| **Feedback Answers** | One row per feedback form with its answers |
| **Pre Screening** | Pre-screenings with candidate, score, requester, and dates |
| **References** | Reference contacts, one row per email address, including lead type and consent columns |

## Exports on other pages

- **Candidates** and **References** pages: a download icon in the filter toolbar exports the list. See below.
- **Leads** page: a download icon exports your leads, including lead type and consent. See [Lead generation](/reports-lead-generation/lead-generation).
- **Overview** dashboard: a download button exports the dashboard as CSV or PDF, and the **Recruiters** table has its own export. See [Read the Overview dashboard](/reports-lead-generation/overview-dashboard).

## Export a list from the Candidates or References page

<Steps>
  <Step title="Filter the list">
    Click the **Filters** (funnel) icon and set your filters. See [Search for past references](/candidates-reference-requests/search-past-references).
  </Step>
  <Step title="Choose Everyone or Myself">
    These exports follow the **Everyone** / **Myself** toggle. Pick **Everyone** for the whole firm.
  </Step>
  <Step title="Click the download icon">
    With the filter toolbar open, click the download icon.
  </Step>
</Steps>

<Warning>
  These exports don't apply every on-screen filter. The References CSV applies the scope, date range, recruiters, types, relationships, and question sets, but not the reference status or job title filters or the search box. The Candidates CSV applies only the scope and date range. Check the file before sharing it.
</Warning>

The References CSV keeps one row per email address, so it can have fewer rows than the list on screen.

## Download one candidate's report

- On a candidate's page, the download button offers **PDF** or **Word**.
- On the candidate's **References** tab, you can download per question set as **PDF**, **Word**, or **CSV** (one row per reference, a column per question).
- On a completed reference, you can download **PDF** or **Word**. The option doesn't appear for declined references.

Which details are hidden on the PDF, and whether it has a watermark, is set in **Configuration → Settings → Documents**. See [Report settings](/account-configuration/report-settings) and [Read a completed reference](/candidates-reference-requests/read-a-completed-reference).

## Columns worth knowing

- **Score**: a percentage from the rating and matrix questions. Zero means none were answered.
- **Consent Given At** and **Consent Text**: on reference and lead exports, when the reference agreed to be contacted and the wording they agreed to. See [Lead generation](/reports-lead-generation/lead-generation).
- **Branch name**: the sub-account a record belongs to, on exports that cover several accounts.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The download icon is missing from the top bar">
    Root recruiters always see it. For other users it depends on a firm setting that isn't in Configuration. Ask a root recruiter to contact [hello@vitay.io](mailto:hello@vitay.io). The PDF and Word downloads on candidate and reference pages aren't affected.
  </Accordion>
  <Accordion title="The CSV doesn't match the screen">
    List exports skip some filters (see the warning above), and the Export window always covers the whole firm. Both start on a default date range, not all time, so check the dates too.
  </Accordion>
  <Accordion title="The file only has headers">
    Nothing matches your dates or filters. Widen the date range or remove filters.
  </Accordion>
  <Accordion title="A column I expected is missing">
    Some columns only exist on certain exports (consent columns are only on reference and lead exports), and some depend on features enabled for your account.
  </Accordion>
</AccordionGroup>
