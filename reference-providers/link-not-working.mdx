title: "The reference link isn't working"
description: "What to do if the link or reference ID in your request email opens an error or doesn't load."
---

If clicking the link in your reference request email leads to an error — or the reference ID you were given isn't being accepted — here's what's likely happening and how to fix it.

## Common reasons a link stops working

**The form has already been submitted**

Once a reference form is submitted, the link is locked. If you see a message like **"Reference has already been filled"**, your submission went through successfully and there's nothing else to do.

**The reference or candidate was removed**

If the recruiter removed you as a reference — or removed the candidate — the link stops working and you'll see a message saying the reference is no longer available. If you think this happened by mistake, reply to your request email and ask the recruiter to re-add you; that creates a new link.

**The link was mangled by your email client**

Long links sometimes get broken across lines or cut short by email apps. Instead of clicking, copy the full URL from the email and paste it into your browser's address bar, making sure no characters are missing and there are no extra spaces at the end.

**Your work network is blocking the link**

Some company networks block external links in emails. Try opening the link on your personal device or using your phone's mobile data instead.

## What to do if none of the above helps

<Steps>
  <Step title="Reply to your request email">
    Open your original reference request email and reply to it — the request typically comes from the recruiter who sent it, so replying is the fastest way to reach them.
  </Step>
  <Step title="Ask them to send a fresh request">
    Let the recruiter know the link isn't working. They can resend the request (which contains the same link) or, if needed, remove and re-add you as a reference — that creates a brand-new link.
  </Step>
</Steps>

<Note>
  Only the recruiter can resend a request or create a new link. There is no self-serve way to generate one.
</Note>
