<Update
  label="August 20, 2026"
  description="Bulk candidate actions, password expiry controls, and smarter multi-language requests"
  tags={["Feature", "Improvement", "Fix"]}
  rss={{
    title: "Bulk candidate actions, password expiry controls, and smarter multi-language requests",
    description: "Act on many candidates at once from the candidates list, set how often your team's passwords must be updated, and send requests in any language knowing the question set is fully translated."
  }}
>
  ### New

  - **Bulk candidate actions.** Select any number of candidates on the
    candidates list and act on all of them at once: update their status, assign
    them to a recruiter, send reminders to unresponsive references, send new
    reference (or feedback / pre-screening) requests, or deactivate them. A
    floating action bar shows your selection and lets you select everything
    matching your current filter.
  - **Configurable password expiry.** Firms that require periodic password
    updates can now choose the expiry window (1–365 days) instead of a fixed 30.
    Enforcement is stricter and more consistent: expiry applies on every
    password change path, recent passwords can't be reused, and users signing in
    through SSO are never asked to update a Vitay password.

  ### Improved

  - **Question sets follow your request language.** When you pick a language for
    a request, Vitay now offers exactly the question sets that are fully
    translated into it — so a reference can never land on a form with missing
    questions. If a set is hidden because its translation is incomplete, you'll
    see a hint with a link to finish the translation, and the editor's language
    dropdown now simply switches which translation you're viewing without
    altering the set.
  - **Full French (Canada) support.** Firms using Français (Canada) now get the
    complete set of email, text-message, and page templates in Québécois French,
    and reference reports (PDFs) render correctly in fr-CA.
  - **Accessibility polish.** Page numbers in pagination are readable again
    (the active page was teal-on-teal), and keyboard focus outlines on grouped
    fields — like the internal-ID field with its Generate button — now wrap the
    whole group instead of cutting across the attached button.
  - **Logo links home.** The Vitay logo on the login pages now takes you to
    vitay.io.

  ### Fixed

  - **French translations repaired.** An audit of the French and French (Canada)
    interface fixed dozens of untranslated strings (including the entire
    feedback and pre-screening vocabulary), typos, and outdated descriptions.
  - **Request language and question set stay consistent.** A request can no
    longer pair, say, a French invitation email with an English-only question
    set — the choices are kept in sync as you change language.
</Update>

<Update
  label="August 17, 2026"
  description="Smoother reference submission and accessibility polish"
  tags={["Improvement", "Fix"]}
  rss={{
    title: "Smoother reference submission and accessibility polish",
    description: "Reference submissions no longer stall on slow connections, question widgets in public flows are fully accessible, and feedback-only firms can now configure everything they need."
  }}
>
  ### Improved

  - **Accessible question widgets.** The interactive question types on public
    reference and feedback pages — sliders, ratings, and multiple-choice
    widgets — are now fully usable with a keyboard and properly announced by
    screen readers, continuing our accessibility program.
  - **Easier-to-see checkboxes.** Checkbox borders across the app and public
    pages are now darker, so controls like the terms-acceptance checkbox are
    clearly visible on any screen.

  ### Fixed

  - **Reference submission no longer stalls.** Submitting a reference could
    occasionally leave the button spinning forever, with no way to tell whether
    the submission went through. Slow back-end notifications no longer hold up
    the submission, and if something does go wrong you now see a clear error
    message instead of a frozen button.
  - **Text formatting in rich-text fields.** Text entered in rich-text editors
    (like lead-generation descriptions) could lose its line breaks or refuse to
    wrap, running off the edge of the card. Formatting is now preserved
    everywhere it's displayed.
  - **Feedback-only firms.** Firms that use Vitay for feedback without candidate
    references can now create feedback question sets and configure feedback
    emails, texts, and pages — these settings were previously blocked.
  - **Credits-used tile.** The credits-used tile on the references dashboard
    could show an error state when usage data was briefly unavailable; it now
    always shows a number.
</Update>

<Update
  label="August 6, 2026"
  description="Job title in templates and a big accessibility upgrade"
  tags={["Feature", "Improvement"]}
  rss={{
    title: "Job title in templates and a big accessibility upgrade",
    description: "Use the job title variable in reference templates, and enjoy a more accessible Vitay — better contrast, full keyboard support, and screen-reader-friendly public forms."
  }}
>
  ### New

  - **Job title in your templates.** Reference and reference-request templates
    now support a `{{job_title}}` variable. Pick it from the variable list in
    **Configuration → Templates** and the position the candidate applied for is
    filled in automatically — so candidates and references always know which
    role the request is about.

  ### Improved

  - **A more accessible Vitay.** We've completed a major accessibility pass
    across the app, with a special focus on the public pages candidates and
    references use. Text contrast now meets WCAG AA throughout (and AAA on the
    public reference flows), every form can be completed with just a keyboard,
    screen readers announce loading states and validation errors, and a
    missing-fields summary points to exactly what's left before submitting.
    Animations are also reduced automatically if your device asks for reduced
    motion.
  - **A refreshed brand teal.** Vitay's default accent color is now a deeper,
    accessible teal — in the app and in your emails, PDF reports, and public
    reference pages. If your firm uses custom branding colors, nothing changes.

  ### Fixed

  - **Adding a candidate who already has a Vitay account.** Creating a candidate
    whose email matched an existing user (for example, adding yourself as a test
    candidate) could fail — it now works reliably.
  - **Question editing glitches.** The question-set and question windows could
    show stale validation — for example, not re-checking the title after
    switching the template toggle, or the answer options after changing a
    question's type. Both now update immediately.
  - **Settings pages after session expiry.** Opening a settings page right after
    your session expired could show an error instead of redirecting to login.
  - **Changing your firm's language.** The new language now applies reliably
    everywhere as soon as you change it.
</Update>

<Update
  label="July 23, 2026"
  description="Share reports with more people and see candidate activity at a glance"
  tags={["Feature", "Improvement"]}
  rss={{
    title: "Share reports with more people and see candidate activity at a glance",
    description: "Add extra report recipients to a candidate, sort your candidate list by last activity, and enjoy a simpler question builder."
  }}
>
  ### New

  - **Send reference reports to more people.** You can now add up to five extra
    email addresses to a candidate, and they'll receive the same PDF reference
    reports as the assigned recruiter — handy for hiring managers or clients who
    need the results without a Vitay login. Turn it on under **Configuration →
    Notifications**, where you can also restrict addable addresses to your
    firm's own email domains for extra safety.
  - **"Last Activity" column on the candidate list.** See at a glance when each
    candidate was last updated — shown as relative time (like "2 hours ago") and
    fully sortable, so the candidates that need attention rise to the top.

  ### Improved

  - **A simpler question builder.** The question category dropdown (Functional,
    Behavioral, Technical) and its column have been removed, along with the
    category score summary in default PDF reports — one less thing to fill in
    when building questionnaires.
</Update>

<Update
  label="July 14, 2026"
  description="Feedback PDFs by email and clearer search feedback"
  tags={["Feature", "Improvement"]}
  rss={{
    title: "Feedback PDFs by email and clearer search feedback",
    description: "Completed feedbacks now arrive as a PDF by email, and search bars show clearer status while you type."
  }}
>
  ### New

  - **Feedback reports now arrive by email.** When a feedback is completed,
    recruiters who have PDF reports enabled now receive the completed feedback
    as a PDF attachment — just like completed references already do. There's no
    new setting to flip: if you've turned on PDF reports for references, feedback
    PDFs are included automatically.

  ### Improved

  - **Clearer search feedback.** Search bars across Vitay now show a spinner
    while a search is running and a "No results found" message when a search
    comes up empty — so you always know whether we're still looking or there's
    simply nothing to show.
</Update>
