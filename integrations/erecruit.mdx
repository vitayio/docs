---
title: "eRecruit integration"
description: "Connect Vitay to eRecruit so candidates are imported automatically and reference requests go out without any manual work."
---

Vitay checks your chosen eRecruit requirements on a schedule, imports candidates in the right status, sends each one a reference request, and attaches completed reference PDFs back to the candidate in eRecruit.

<Note>
  Connecting or disconnecting eRecruit requires the root recruiter role in Vitay. You need your eRecruit site URL, API Client ID and Client Secret, and the eRecruit IDs listed in the steps below. Contact [hello@vitay.io](mailto:hello@vitay.io) if you'd like help finding them.
</Note>

## What the integration does

- Imports candidates. Candidates in the requirements and status you choose are imported with their name, email, and mobile phone.
- Sends reference requests. Each imported candidate gets a reference request straight away. Vitay uses the question set whose name matches the eRecruit requirement, or your first active question set if none matches.
- Assigns a recruiter. The candidate goes to the Vitay user whose email matches the requirement's owner in eRecruit (or, if the requirement has no owner, the candidate's primary owner). Otherwise it goes to your firm's default root recruiter.
- Attaches completed reports. When a reference is completed, a PDF of it is uploaded to the candidate's attachments in eRecruit.
- Manual actions. Recruiters can push a Vitay candidate to eRecruit, or upload a reference document, from the **Synchronize** menu.

## Connect eRecruit

<Steps>
  <Step title="Open the eRecruit card">
    In the **Configuration** area, select **Integrations** and click the **eRecruit** card.
  </Step>
  <Step title="Enter your eRecruit details">
    Fill in:

    - **Site url**: the address of your eRecruit system.
    - **Client ID** and **Client secret**: your eRecruit API credentials.
    - **Requirement(s) ID**: the requirements Vitay should watch. Separate several with commas.
    - **Status ID**: the candidate status that triggers an import.
    - **Department ID** (optional): limit imports to these departments, separated by commas.
    - **Attachment Type Id**: where completed reports are filed in eRecruit.
    - **Folder group ID** and **Ad source ID**: used when you push candidates from Vitay to eRecruit.

    ![SCREENSHOT(erecruit-connect-modal): The eRecruit connect dialog with the site URL, ID and API credential fields](/images/placeholder.png)
  </Step>
  <Step title="Submit">
    Click **Submit**. Vitay signs in to eRecruit with your credentials before saving them. Once accepted, the card shows **Active**.
  </Step>
</Steps>

## How often it syncs

Vitay checks eRecruit about every 90 minutes, so a candidate who reaches the right status is usually in Vitay, with their request sent, within a couple of hours. There's nothing to set up on the eRecruit side. Report uploads happen as each reference is completed, and the **Synchronize** actions run as soon as you use them.

## Disconnect eRecruit

A root recruiter clicks the **eRecruit** card and chooses **Delete Integration**.

## Troubleshooting

<AccordionGroup>
  <Accordion title="A candidate in eRecruit never appeared in Vitay">
    Vitay only imports candidates in a watched requirement, in the configured status, and (if you set departments) in one of those departments. Candidates without a valid email address in eRecruit are skipped. If everything looks right, contact [hello@vitay.io](mailto:hello@vitay.io).
  </Accordion>
  <Accordion title="An imported candidate was assigned to the wrong recruiter">
    Vitay matches the eRecruit owner's email to a Vitay user at your firm. Make sure your recruiters use the same email address in both systems. Without a match, the candidate goes to your default root recruiter.
  </Accordion>
  <Accordion title="Reference requests use the wrong question set">
    Vitay picks the question set whose title exactly matches the eRecruit requirement name, and falls back to your first active question set. To control the questions, name a question set after the requirement.
  </Accordion>
  <Accordion title="A completed reference report isn't showing in eRecruit">
    Reports are only uploaded for candidates linked to an eRecruit record. Candidates imported by the sync are linked automatically. If a report is missing, contact [hello@vitay.io](mailto:hello@vitay.io).
  </Accordion>
</AccordionGroup>
