---
title: "JobDiva integration"
description: "Connect Vitay to JobDiva so flagged candidates are imported and sent a reference request automatically, and push candidates and reference reports back to JobDiva."
---

Vitay checks JobDiva every hour for candidates you've flagged, imports them, and sends each one a reference request. Recruiters can also push candidates and reference reports from Vitay to JobDiva.

<Note>
  Only a root recruiter can connect or disconnect JobDiva. You need your JobDiva API Client ID, username, and password. Flagging candidates relies on a Vitay sync field on your JobDiva candidate records, which you set up with the Vitay team, so contact [hello@vitay.io](mailto:hello@vitay.io) before you start.
</Note>

## What the integration does

- Imports flagged candidates. Every hour, Vitay looks at JobDiva candidates created or updated that day and imports the ones whose Vitay sync field is *Yes* (name, email, and JobDiva ID).
- Sends reference requests. Each imported candidate gets a reference request straight away, using your first active question set, with automatic reminders.
- Pushes candidates to JobDiva. Create a JobDiva candidate from a Vitay candidate. Their references are added as JobDiva contacts of type *Reference*.
- Uploads reference reports. Attach a PDF of the candidate's references to their file in JobDiva.

## Connect JobDiva

<Steps>
  <Step title="Open the JobDiva card">
    In the **Configuration** area, select **Integrations** and click the **JobDiva** card.
  </Step>
  <Step title="Enter your JobDiva API credentials">
    Fill in **Client ID**, **Username**, and **Password**, then click **Submit**. Vitay checks them with JobDiva before saving. If JobDiva rejects them, the connection isn't created.

    ![SCREENSHOT(jobdiva-connect-modal): The JobDiva connect dialog with the Client ID, Username and Password fields](/images/placeholder.png)
  </Step>
  <Step title="Check the card shows Active">
    The JobDiva card now shows **Active**. Flagged candidates are picked up from the next hourly check.
  </Step>
</Steps>

## What syncs, and when

<Steps>
  <Step title="Vitay checks JobDiva every hour">
    Each check looks at candidates created or updated in JobDiva that day and keeps the ones whose Vitay sync field is *Yes*.
  </Step>
  <Step title="New candidates are imported">
    They're assigned to your firm's default root recruiter. Candidates without an email address are skipped, and a candidate whose email is already in Vitay isn't duplicated.
  </Step>
  <Step title="A reference request goes out">
    Vitay sends the request using your first active question set. A flagged candidate who already exists in Vitay gets one too, but only if they don't have one yet.
  </Step>
  <Step title="Push to JobDiva when you're ready">
    Reports aren't uploaded to JobDiva automatically. Use the actions below.
  </Step>
</Steps>

### Push a candidate or a report

Once connected, recruiters see these actions on the candidate page:

- **Synchronize to Jobdiva**, in the **Synchronize** menu, creates the candidate in JobDiva with a *Reference* contact for each of their references. Each candidate can be pushed once.
- **Upload document to Jobdiva**, under the **Upload report** button next to the download button, attaches a PDF of the candidate's references to their JobDiva file. The candidate must already be linked to JobDiva, and at least one reference must be completed.

## Disconnect JobDiva

A root recruiter clicks the **JobDiva** card and chooses **Delete Integration**. The hourly import stops.

## Troubleshooting

<AccordionGroup>
  <Accordion title="A candidate I flagged in JobDiva never appeared in Vitay">
    Check that the Vitay sync field is *Yes* and that the candidate has an email address. Each check only looks at records created or updated that day, so if you set the flag earlier, update the candidate in JobDiva again. Candidates who already have a reference request in Vitay are left as they are.
  </Accordion>
  <Accordion title="The reference request used the wrong question set">
    The import always uses your first active question set. There's no per-candidate choice. Contact [hello@vitay.io](mailto:hello@vitay.io) if the wrong questions are going out.
  </Accordion>
  <Accordion title="Imported candidates are assigned to the wrong recruiter">
    Imported candidates always go to your firm's default root recruiter. Reassign them from the candidate page in Vitay.
  </Accordion>
  <Accordion title="'Candidate already exists' when pushing a candidate">
    The candidate is already linked to a JobDiva record, either imported by the sync or pushed earlier. There's nothing more to do.
  </Accordion>
  <Accordion title="A reference report won't upload to JobDiva">
    Link the candidate to JobDiva first with **Synchronize to Jobdiva**, and wait until at least one reference is complete. If it still fails, contact [hello@vitay.io](mailto:hello@vitay.io).
  </Accordion>
  <Accordion title="Nothing is importing any more">
    If your JobDiva API password or credentials changed, Vitay can no longer sign in. A root recruiter clicks the **JobDiva** card, chooses **Delete Integration**, and connects again with the new details.
  </Accordion>
</AccordionGroup>
