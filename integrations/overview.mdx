Vitay integrates with popular applicant tracking systems (ATS) so your team can run reference checks alongside your ATS and get completed reference reports back onto the candidate's record.

<Note>
  Setting up an integration requires **root recruiter** access in Vitay. The exact steps vary by ATS — see the article for your platform below.
</Note>


![The Integrations gallery in Configuration](/images/integrations.png)

## What integrations do

Depending on the platform, a connected integration can:

- **Import candidates** from your ATS into Vitay — in one click, or automatically as candidates become ready for reference checks.
- **Send reference requests** for imported candidates without re-entering their details.
- **Get completed reference reports back into your ATS** — some integrations push the completed report to the candidate's record automatically, others add it through a manual upload action in Vitay. See the article for your platform for exactly what it supports.

Connection credentials are stored on your Vitay account, so day-to-day use requires no re-authentication.

## Supported integrations

<CardGroup cols={2}>
  <Card title="Bullhorn" icon="bullseye" href="/integrations/bullhorn">
    Connect with your Bullhorn credentials to import candidates, push reference reports, and run reference requests inside Bullhorn.
  </Card>
  <Card title="eRecruit" icon="rotate" href="/integrations/erecruit">
    Scheduled sync that imports candidates from eRecruit and sends reference requests automatically.
  </Card>
  <Card title="JobAdder" icon="briefcase" href="/integrations/jobadder">
    OAuth-based connection that adds a Vitay action button inside JobAdder.
  </Card>
  <Card title="Greenhouse" icon="seedling" href="/integrations/greenhouse">
    API-key connection that imports flagged candidates from Greenhouse and posts progress notes back to the candidate's activity feed.
  </Card>
  <Card title="JobDiva" icon="users" href="/integrations/jobdiva">
    API-credential connection that imports candidates you've flagged in JobDiva and sends each one a reference request.
  </Card>
  <Card title="TargetRecruit" icon="cloud" href="/integrations/targetrecruit">
    Salesforce-based connection that exchanges candidates and references with TargetRecruit and files completed reference PDFs on the candidate's record.
  </Card>
</CardGroup>

<Note>
  Accounts start with a limit of **one active integration**. If you connect up to

  been reached — contact [hello@vitay.io](mailto:hello@vitay.io) to have it raised.
</Note>
