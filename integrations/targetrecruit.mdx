description: "Connect Vitay to TargetRecruit (Salesforce) so candidates and references flow between the two systems and completed reference PDFs land on the candidate's record."
---

TargetRecruit, a Salesforce-based ATS, can send candidates and references to Vitay and trigger reference requests. Vitay writes completed references and their PDFs back to the candidate's record.

<Note>
  TargetRecruit is set up together with the Vitay team, because the automatic flows depend on Vitay fields and a webhook on your TargetRecruit side. Connecting or disconnecting requires the root recruiter role in Vitay. You need your Salesforce site URL, a connected app's Client ID and Client Secret, an integration user's username, password, and (if your org requires it) security token, and the record type ID for candidate contacts. Contact [hello@vitay.io](mailto:hello@vitay.io) to get started.
</Note>

## What the integration does

- Imports candidates. When TargetRecruit sends a candidate, Vitay creates them (or matches an existing candidate with the same email) and assigns them to the recruiter you specify, or to your firm's default root recruiter.
- Sends reference requests. If the candidate is flagged to get a request, Vitay sends one with the question set chosen in TargetRecruit, or a reference question set from your account if none was chosen. An open request with the same question set isn't duplicated.
- Imports references. A reference added to a linked candidate in TargetRecruit is created in Vitay and sent the reference form.
- Writes completed references back. When a reference is completed, Vitay creates it on the candidate's TargetRecruit record if it isn't there yet. If it is, Vitay attaches the completed reference PDF to the candidate's *Credentials* record.
- Manual actions. Recruiters can push a candidate or upload a reference PDF from the **Synchronize** menu.

## Connect TargetRecruit

The Vitay team walks you through the fields and webhook on the TargetRecruit side. Then a root recruiter enters the credentials in Vitay:

<Steps>
  <Step title="Open the Target Recruit card">
    In the **Configuration** area, select **Integrations** and click the **Target Recruit** card.
  </Step>
  <Step title="Enter your Salesforce details">
    Fill in **Site url**, **Client ID**, **Client secret**, **Username**, **Password**, and **Candidate record type id**. **Token** is the user's Salesforce security token; leave it empty if your org doesn't require one. Click **Submit**.

    ![SCREENSHOT(targetrecruit-connect-modal): The Target Recruit connect dialog with the site URL, token, record type ID and credential fields](/images/placeholder.png)
  </Step>
  <Step title="Check the card shows Active">
    Vitay signs in to Salesforce with these details before saving them. If Salesforce rejects them, the connection isn't created.
  </Step>
</Steps>

## What syncs, and when

Nothing runs on a schedule. Things happen when TargetRecruit notifies Vitay, when a reference is completed, or when a recruiter uses a manual action.

<Steps>
  <Step title="TargetRecruit sends a candidate">
    Vitay creates the candidate (name, email, mobile phone, TargetRecruit ID) or matches an existing one by email. Candidates without an email are ignored. If the candidate is flagged for a request, it goes out immediately.
  </Step>
  <Step title="TargetRecruit sends a reference">
    For a linked candidate, Vitay creates the reference (name, email, phone, company, relationship, start date) and sends the reference form.
  </Step>
  <Step title="A reference is completed in Vitay">
    Vitay creates the reference in TargetRecruit if needed. Otherwise it attaches the completed PDF (*Candidate name - Reference name.pdf*) to the candidate's *Credentials* record.
  </Step>
  <Step title="Manual pushes from Vitay">
    **Synchronize to Target Recruit** creates the candidate contact and its *Credentials* record. **Upload document to Target Recruit** attaches the reference PDF to the candidate, and to the reference record if it's linked.
  </Step>
</Steps>

## Disconnect TargetRecruit

A root recruiter clicks the **Target Recruit** card and chooses **Delete Integration**. Vitay stops accepting TargetRecruit updates for your firm and no longer writes anything back.

## Troubleshooting

<AccordionGroup>
  <Accordion title="A candidate sent from TargetRecruit never appeared in Vitay">
    Vitay ignores candidates without an email address and candidates already linked to the integration. If the candidate is new and has an email, contact [hello@vitay.io](mailto:hello@vitay.io) to check the webhook on your TargetRecruit side.
  </Accordion>
  <Accordion title="No reference request was sent for an imported candidate">
    A request is only sent when the candidate is flagged for one in TargetRecruit, and not if they already have an open request with the same question set.
  </Accordion>
  <Accordion title="A reference added in TargetRecruit didn't get the form">
    References are only imported for candidates already linked to the integration, so send the candidate first. The reference also needs an email address or phone number.
  </Accordion>
  <Accordion title="'Candidate already exists' when pushing a candidate">
    The candidate is already linked to a TargetRecruit record. There's nothing more to do.
  </Accordion>
  <Accordion title="A reference PDF isn't on the candidate's record">
    The PDF is attached only once the reference is complete and linked to TargetRecruit. For a reference created in Vitay, its first completion creates it in TargetRecruit. Use **Upload document to Target Recruit** on the completed reference to attach the PDF.
  </Accordion>
  <Accordion title="Actions fail after a password or security token change">
    Vitay signs in to Salesforce with the stored details for every action. A root recruiter clicks the **Target Recruit** card, chooses **Delete Integration**, and connects again with the new details.
  </Accordion>
</AccordionGroup>
