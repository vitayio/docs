Connect Vitay to Bullhorn to push candidates and reference reports into Bullhorn. Firms on the in-app experience can also request references and read results from inside Bullhorn.

<Note>
  Only a root recruiter can connect or disconnect Bullhorn. You need your Bullhorn API Client ID and Client Secret, plus the username and password of a dedicated Bullhorn API user (not a recruiter's login).
</Note>

## What the integration does

- Push candidates to Bullhorn. Create a Bullhorn candidate from a Vitay candidate in one click. Vitay sets the record owner to the Bullhorn user whose email matches the candidate's Vitay recruiter.
- Push reference reports. Attach a PDF of the completed references to the candidate's file in Bullhorn.
- Work inside Bullhorn. With the in-app experience, recruiters request references and read results from a tab, a card, and menu actions in Bullhorn. Completed reports are then delivered to the Bullhorn candidate automatically.

## Connect Bullhorn

<Steps>
  <Step title="Open the Bullhorn card">
    In the **Configuration** area, select **Integrations** and click the **Bullhorn** card.
  </Step>
  <Step title="Enter your Bullhorn API credentials">
    Fill in the Client ID, Client secret, API username, and password, then click **Submit**. On the in-app experience the fields are labelled **OAuth Client ID**, **OAuth Client Secret**, **Bullhorn API Username**, and **Bullhorn API Password**.

    ![SCREENSHOT(bullhorn-connect-modal): The Bullhorn connect dialog with the Bullhorn API credential fields](/images/placeholder.png)
  </Step>
  <Step title="Confirm the connection">
    When Bullhorn accepts the credentials, the card shows **Active**. The Vitay team is notified of new connections and may contact you to finish validating it. If Bullhorn rejects the login, you see its reason. A brand-new API user may first need to sign in to Bullhorn once to accept its terms of service.
  </Step>
</Steps>

## Push candidates and reports

Once connected, recruiters see a **Synchronize** menu on the candidate page and on completed references:

- **Synchronize to Bullhorn** on the candidate page creates the candidate in Bullhorn. Each candidate can be pushed once. A second try shows "Candidate already synched".
- **Upload document to Bullhorn** on a completed reference attaches a PDF of the reference to the candidate in Bullhorn. The candidate must already be synchronized.

## Work inside Bullhorn

The in-app experience adds Vitay to four places in Bullhorn, each set up in Bullhorn's View Layout editor with a URL that Vitay generates for your firm.

<Note>
  The Vitay team turns the in-app experience on for each firm. If the connected Bullhorn dialog doesn't show the URL rows below, contact [hello@vitay.io](mailto:hello@vitay.io).
</Note>

| Placement | What recruiters get |
| --- | --- |
| Custom Tab | A Vitay tab on the candidate record to request references and read results. |
| Card Tab | A reference-status card on the candidate overview. |
| Custom Menu Action | A **Request references** entry in the candidate action menu. |
| Custom List Action | Request references for several selected candidates at once. |

### Add a placement

<Steps>
  <Step title="Copy the URL from Vitay">
    Click the **Bullhorn** card. The dialog has a row for each placement: **Embed URL** (Custom Tab), **Card URL** (Card Tab), **Bullhorn menu action URL**, and **Bullhorn list action URL**. Click the copy button next to the one you need.

    ![SCREENSHOT(bullhorn-placement-urls): The connected Bullhorn dialog with the Embed URL, Card URL, menu action URL and list action URL rows](/images/placeholder.png)
  </Step>
  <Step title="Paste it into Bullhorn">
    In Bullhorn, open the View Layout editor for the Candidate entity and add the URL under **Custom Tabs**, **Card Tabs**, **Custom Menu Actions**, or **Custom List Actions** to match the row you copied.
  </Step>
  <Step title="Save and reload Bullhorn">
    The new tab, card, or action appears for the users covered by that layout.
  </Step>
</Steps>

### Request references for several candidates

<Steps>
  <Step title="Select candidates in Bullhorn">
    In a Bullhorn candidate list, tick the candidates you want and choose the Vitay list action. A Vitay window opens showing how many you selected.
  </Step>
  <Step title="Fill in the request once">
    Choose the question set and the number of references, add an optional note, and click **Send request**. The details apply to every selected candidate.
  </Step>
  <Step title="Check the results">
    Each candidate gets a result line: **References requested**, **Request already in progress** (nothing was duplicated), or **Could not create the request**. Keep the window open until the summary appears. Candidates not reached before you close it aren't requested, and running the action again on them is safe.
  </Step>
</Steps>

## How often it syncs

Pushing a candidate, uploading a report, and requesting references from Bullhorn happen as soon as you do them. Vitay keeps the Bullhorn connection signed in, so recruiters don't need to re-enter credentials.

If the Vitay team has turned on automatic requests for your firm, Vitay watches your Bullhorn job submissions. When a candidate reaches the stage you agreed on, a reference request goes out, normally within minutes. A request in progress is cancelled if the candidate reaches one of the stages you chose for that.

## Disconnect Bullhorn

A root recruiter clicks the **Bullhorn** card and chooses **Delete Integration**.

## Troubleshooting

<AccordionGroup>
  <Accordion title="We got a 'Bullhorn Integration Disconnected' email">
    Vitay sends this to your firm's active root recruiters when it can no longer sign in to Bullhorn, usually because the API user's password or the client credentials changed. Automatic requests through Bullhorn are paused until you reconnect. Work you do by hand in Vitay is unaffected.

    To fix it, a root recruiter clicks the **Bullhorn** card, chooses **Delete Integration**, and connects again with the current details. The email is sent at most once a day per connection.
  </Accordion>
  <Accordion title="The Synchronize menu is missing">
    It only appears once an integration is connected for your firm. Ask a root recruiter to check that the Bullhorn card shows **Active**.
  </Accordion>
  <Accordion title="'Candidate already synched' when pushing a candidate">
    The candidate is already linked to a Bullhorn record. There's nothing more to do.
  </Accordion>
  <Accordion title="A reference report won't upload to Bullhorn">
    Push the candidate with **Synchronize to Bullhorn** first. If the candidate already exists in Bullhorn but Vitay doesn't know about it, contact [hello@vitay.io](mailto:hello@vitay.io).
  </Accordion>
  <Accordion title="The dialog says 'Connected via the previous Bullhorn integration'">
    Your firm is on the in-app experience but still connected the older way, so the placement URLs aren't available. Contact [hello@vitay.io](mailto:hello@vitay.io) to upgrade the connection.
  </Accordion>
  <Accordion title="A Vitay tab in Bullhorn shows an error">
    The message names the problem. "This tab is missing its Vitay configuration" means the URL needs to be copied again from the connected Bullhorn dialog. "This tab URL belongs to a different Bullhorn account" means Vitay is connected to another Bullhorn account, so reconnect with the right credentials. "Bullhorn could not be reached" usually clears if you try again shortly.
  </Accordion>
</AccordionGroup>
